# 固定引导文字收紧记录

## 范围与依据

2026-11-17 对 `crates/sa-engine/src/guides.rs` 做小幅措辞压缩。起点为本轮操作前的工作区内容，已包含真实 Hydrogen 验收后新增的续派字段约束。该起点与 Git HEAD 的内容有差异，以下摘要记录的是实际文本基线。

参考[真实协作验收](collaboration-acceptance.md)中的控制拒绝、模型仍声称已经派工，以及续派消息 ID 解析缺口。此次保留这些失败对应的明确约束，并保留各控制示例。委派仍使用 `SA_SEND`。

## 修改

- 合并主控选择角色、协作人数和执行端能力的冗长叙述，保留零协作者、同执行端多实例、并发上限及无层数配额。
- 压缩派工格式及 ECONOMY 的常规措辞，保留任务规模、紧耦合与同文件写入限制、自包含交接要求、低成本且可靠的模型选择。
- 续派说明继续保留同一会话和上下文，删除未经本次对照验证的确定成本及上下文损失比较。
- 保留 `protocol.rejected` 的通用处理要求，以及续派段中“被拒绝就没有执行”的具体提醒。真实验收出现过的错误使这两处提醒仍有保留价值。
- 保留 `SA_ASK`、`SA_NOTE`、`SA_REPORT`、持续运行的 `SA_FINISH` 等控制、权限与外部动作边界、平台检查覆盖范围、反幻觉要求。续派仍只接受 `id`、`continue`、`body`，后续审查由新任务的 `after` 表达。
- 配合本轮候选验证队列，将工作区说明改为操作者必须在工作台确认合入，继续保留“子任务完成不等于合入”及禁止模型绕过平台合入、移除他人工作树的边界。平台负责的验证与退回说明由队列启用时的附加引导提供。
